$ boomux --help
Native persistent terminal workspaces

Usage: boomux [OPTIONS] [PATH] [-- <COMMAND>...] [SUBCOMMAND]

Commands:
  ui            Open the interactive workspace dashboard
  web           Serve the mobile Agent dashboard and exact-run terminals on loopback
  doctor        Check that Boomux's dependencies and daemon are available
  setup         Discover and configure local Agent harnesses and desktop integration
  capabilities  Report stable integration capabilities without starting the daemon
  list          List all managed shells
  shells        List shells in the current Boomux workspace
  read          Read retained output from a shell name or shell ID
  events        Read a bounded batch of daemon events
  close         Close a shell by name, shell ID, or latest focused Boomux terminal
  config        Inspect and edit layered Boomux configuration
  update        Check for or install an official local Boomux release
  uninstall     Remove this official Boomux release installation
  project       Discover configured projects
  workspace     Manage workspaces
  desktop       Navigate Boomux Workspaces through an optional desktop layer
  node          Manage this Boomux Node identity
  shell         Manage shells
  launcher      Manage workspace launchers
  agent         Inspect and report external agent runtime state
  attention     Inspect and acknowledge blocked or completed Agent work
  notification  Test configured desktop and sound notification delivery
  session       Discover projected agent sessions
  integration   Inspect and install supported harness integrations
  skill         Manage the vendor-neutral Boomux Agent Skill
  opencode      Manage the Boomux OpenCode integration
  pi            Manage the Boomux Pi integration
  open          Open a shell in a new terminal window
  daemon        Manage the background PTY daemon
  help          Print this message or the help of the given subcommand(s)

Arguments:
  [PATH]        Open or create a persistent terminal in this directory
  [COMMAND]...  Command and arguments to run instead of the login shell

Options:
      --json                      Emit the stable boomux.cli/v1 envelope for commands advertised by capabilities
      --remote <TARGET>           Connect ad hoc to one Boomux Node through OpenSSH
  -n, --name <NAME>               Name of the workspace group
      --new                       Open the terminal in a new window instead of attaching here
      --terminal <DESKTOP_ENTRY>  XDG desktop entry to use for windows opened by this invocation
  -h, --help                      Print help
  -V, --version                   Print version
