# Observe ordinary Pi sessions before explicit adoption

An explicitly installed global Pi observer extension may report privacy-bounded structured lifecycle facts for visible Pi sessions started in ordinary terminals, so the Companion Plugin can list them as observed and unassigned. Discovery grants no workflow, assignment, writer, PTY, terminal, or process authority: converting one into an Agent Run requires exact current identity, a Team Goal on the same Execution Node, explicit user confirmation, same-process acknowledgement, and reconciliation. MVP ordinary-terminal observation is local to the Omarchy Node; sessions launched through Omarchestra's managed Boomux path remain the only ones that begin with Team Goal membership and PTY persistence guarantees.
