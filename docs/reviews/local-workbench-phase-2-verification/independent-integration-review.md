## Initial independent findings and resolved regressions

1. **Loaded Companion status lied during a reload window:** `native-owner.ts` returned `presentation: open` before its periodic tick detected a changed generation. A reviewer traced the actual owner-status branch, not only a test. The `status` branch now verifies the loaded contract/generation synchronously and returns `unavailable` instead of a false `open`; it does **not** tick the host or apply pending intents. `phase-2-native-owner.test.ts` exercises reload → immediate status without an intervening tick, asserts unavailable and unchanged owner epoch.
2. **Selected Project/Goal disappeared past page one after reopening:** paged arrays excluded durable selection; QML derived context only from those arrays. Projection now includes separately validated exact selected Project/Goal summaries, anchors a fresh page on the selection, and preserves both summaries while browsing away. QML header, Goal, checks and overview consume the explicit context. Native-owner and offscreen-QML regressions cover >64 Projects, >64 Goals, fresh authority and page navigation; malformed/mismatched selected identities fail schema validation.
3. **The approved Add agent path could not request an Adoption:** it depended on a proposal that only the overview card could create. The form now selects an exact runner-provided `(observed session, Role, choiceId)` tuple; it never parses a display label or manufactures authority. Request goes through the existing confirmation dialog, then committed proposal review and authorization; mismatched Role disables request. The composed Qt→adapter→runner→framed fake-Pi test exercises the **Add agent** path, including an unavailable Role, rather than substituting an overview-card click.

Follow-up reviewers inspected these repairs plus owner/bridge and QML/adapter path dependencies and reported **no remaining blocking findings in reviewed sources**. This is their read-only conclusion, not host self-certification. They did not execute the host tests or independently attest installed-shell behavior.
