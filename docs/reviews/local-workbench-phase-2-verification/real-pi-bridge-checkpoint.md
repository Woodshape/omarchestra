## Contract and evidence

- `pi-extension.ts` is an explicit Pi extension entry. The factory is idle until TUI `session_start`; it uses public session ID, idle/pending-message and input-source fields only, never the input body, conversation, editor or tool content. It keeps random process/extension capabilities in the surviving extension and retains a source-only manual-input marker across disconnection or uncertain writes until an exact `input_received` response. The registry responds only after a synchronous durable takeover callback returns; the current owner entry supplies no such callback. Ordinary Pi remains usable if the socket is absent. R1 slash-command/`user_bash` activity limitations remain.
- The new versioned bridge codec and byte-stream channel accept exact closed NDJSON shapes, canonical wire bytes, strict UTF-8, bounded frames/partial buffers and ordered chunks; failures destroy only the offending channel. The owner listener requires the runner's exact private runtime root, refuses a non-private directory, creates a 0600 socket and refuses ordinary teardown on socket-inode drift, since Node's `server.close()` unlinks by pathname. On drift it unrefs the now non-admitting listener until owner-process exit rather than deleting a foreign path. Same-UID concurrent pathname races are not defended by this local socket boundary. All registered peers are closed on owner shutdown.
- The owner registry derives Node identity from its runner, issues fresh per-connection capabilities, checks exact durable incarnation membership and independent retirement/purge fences before observation, caps current observations at 64, bounds replay state, expires leases on a monotonic clock, and distinguishes ordinary observation from retained committed membership. Superseded and expired connections cannot publish; Pi session replacement invalidates the previous session. Input from a retained committed identity is never delegated after retirement.
- Negative tests cover fragmented/multi-frame bytes, malformed/oversized frames, forbidden content fields and throwing input-content getters, wrong challenges, sequence regression, changed duplicates, supersession, lease expiry, capacity, committed identity, late retired input, offline input, persistence failure with no takeover receipt, socket-inode replacement, and a real local socket with a fake Pi host.
